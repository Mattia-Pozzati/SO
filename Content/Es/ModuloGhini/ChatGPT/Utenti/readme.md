## Script per la gestione di utenti
Scrivi uno script che accetta un'azione come argomento (aggiungi, rimuovi o lista) e:

### aggiungi
- chiede il nome dell'utente 
- aggiunge a un file chiamato utenti.txt.
### rimuovi
- chiede il nome dell'utente 
- lo rimuove dal file.
### lista
- stampa tutti gli utenti registrati.

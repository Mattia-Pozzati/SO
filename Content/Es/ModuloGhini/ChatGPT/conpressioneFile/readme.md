## Compressione dei file
Scrivi uno script che:

 - Cerca tutti i file con una specifica estensione (ad esempio .log) in una directory specificata.
 - Comprime questi file in un archivio .tar.gz.
- Salva l'archivio in una  directory di backup con un nome basato sulla data corrente (ad esempio backup_YYYYMMDD.tar.gz).
